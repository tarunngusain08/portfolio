## Product

memoREELS transforms a device's local photos and videos into a vertically scrolling feed for revisiting personal memories. Playback and browsing stay on device; the project describes no internet permission and no data sharing.

## Features and implementation

- Mix videos and photos in one feed or browse dedicated media tabs, with loop, autoplay and playback controls.
- Present photos through motion, stacked-photo, Polaroid and collage layouts.
- Add memory-journal notes, time capsules, “this day” memories, favorites, a location map and voice notes.
- Categorize media with on-device ML Kit image labeling and face detection, then browse categories and search by tags.
- Structure the Android application around Kotlin, Jetpack Compose, Media3, Room, Paging, DataStore and WorkManager, with MVVM and clean architecture.

The README also links to an installable APK archive for people who want to try the Android app. The source repository is the best place to review its current features and setup instructions.
