## The problem

AI-assisted engineering workflows are hard to trust when their outputs cannot be reproduced or compared after a change. AgentOps treats evaluation and regression checks as part of the workflow, so repository analysis can be reviewed against evidence and a tracked baseline.

## Workflows

The project includes repository architecture reports, evidence-backed onboarding guides, architecture-level pull-request reviews, fixture-driven incident RCA, golden-task evaluation and regression reports. Workflow traces and evaluation artifacts are local JSON files.

Repository intelligence is deliberately shallow and explainable, with support for Python, TypeScript/JavaScript and Go. Evaluation uses versioned fixtures, weighted deterministic checks and tracked baselines; GitHub Actions blocks P0 evaluation failures and P0 regressions.

## Scope

The repository describes AgentOps as a local-first, feature-complete v1.0.0 portfolio project. It is not a hosted SaaS, multi-agent orchestration platform, vector-search system or production telemetry service. The design keeps the project centered on reviewable engineering workflows and regression evidence.

**Stack:** Python, TypeScript/JavaScript, Go, pytest, React, GitHub Actions.
